# Asset provenance audit — 2026-11-06

## Evidence from the original work

The original `art-direction-v2.md` says the generated artwork used two user reference images and a matching night wallpaper. It asks the generator to preserve the cat character and cut-paper look. The subsequent icon prompt set uses an existing generated folder as a style reference. The original reference files' online sources and permissions were not recorded in those notes.

The project owner recalls that the reference was found on Pinterest. No pin URL or original creator has yet been identified. The owner prefers to retain the current design while this is investigated; this preference does not establish the reference's reuse permissions.

The original cursor README and `build-cursors.py` show locally drawn geometric paths, CUR/ANI encoding and preview generation. `simple-folders.py` and `toggle-icon.py` likewise draw the plain folder colors and simple day/night button from shapes. The two paper-art buttons have their own recorded image-generation prompts.

## Online search

Text and image searches covered the theme name, black-cat folder packs, pastel blue/yellow cat icons, cut-paper textures, and cat/moon desktop wallpapers. The search found related work, including:

- [Dreamy Black Cat Folder Icons on Etsy](https://www.etsy.com/listing/4303052787/dreamy-black-cat-folder-icons-black-cat)
- [Mystical Black Cat Wallpaper](https://www.livewallpapers.com/wallpapers/mystical-black-cat-wallpaper-147.html)
- [Whimsical cat under crescent moon on Rawpixel](https://www.rawpixel.com/image/22484050/whimsical-cat-under-crescent-moon-desktop-wallpaper)

These are search leads, not established sources for this repository. No exact match was confirmed in the inspected search results. Some original listing images could not be retrieved for full-resolution comparison. Similar subject matter and colors are not evidence of copying.

This was a descriptive text/image search, not a comprehensive reverse-image search using every repository asset. It cannot establish uniqueness or prove that no online source exists.
