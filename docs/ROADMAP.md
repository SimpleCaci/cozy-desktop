# Roadmap

This is a list of work to do, not a release schedule. Dates depend on testing and
available maintainer time.

## Before a stable release

- [ ] Validate full install/reset on disposable Windows 10 and 11 desktops, including redirected folders and mixed-orientation monitors. [Issue 1](https://github.com/SimpleCaci/cozy-desktop/issues/1)
- [ ] Verify scheduled switching after sleep, missed triggers, sign-in and daylight-saving changes. [Issue 2](https://github.com/SimpleCaci/cozy-desktop/issues/2)
- [ ] Identify the Pinterest reference's original creator and permissions before bundling Sunbeam Kitty in releases. [Issue 3](https://github.com/SimpleCaci/cozy-desktop/issues/3)
- [ ] Review failure recovery on a PC with an existing custom icon pack.
- [ ] Decide whether executable signing is feasible; previews are currently unsigned.

## Small contributions

- Add distinct source-drawn symbols to the Starter folder icons, while retaining readability at 16–32 pixels.
- Try the setup guide as a first-time user and propose specific wording changes where a step is unclear. [Good first issue](https://github.com/SimpleCaci/cozy-desktop/issues/4)
- Add troubleshooting entries for reproducible Windows build differences.

## Later ideas

- A theme picker that validates assets before installation.
- Import/export for user-created themes with recorded credits and permissions.
- Performance measurements for launch/switch operations, with a reproducible method.
- A GitHub Pages gallery if there are enough cleared themes and examples to add something beyond this README.

Live screenshots and demo recording are deferred at the project owner's request.
Artwork previews in the README are labelled as previews.
