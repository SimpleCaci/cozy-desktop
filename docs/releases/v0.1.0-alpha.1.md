# Cozy Desktop 0.1.0-alpha.1

An experimental Windows theme toolkit with a source-drawn Starter theme.

## Included

- Day, Night, Auto and Toggle desktop buttons.
- Landscape/portrait wallpapers and Windows light/dark switching.
- System and folder icons, plus 17 native cursor roles.
- Optional per-user scheduling and backups of tracked settings.
- A reset command that returns those settings to their pre-install values.
- A ZIP with the compiled button, scripts, Starter assets, notices and a setup guide; a SHA-256 checksum accompanies it.

## Fixes during preparation

- Reject linked assets and directories that could escape a theme's path boundary.
- Avoid pinning the Recycle Bin to a static class icon; preserve its empty/full mappings and the original registry values for reset.
- Allow Windows to return paths for missing known folders so they can be skipped.
- Use the selected theme's button artwork rather than a hard-coded Sunbeam Kitty path.

## Read before installing

This is an unsigned preview. Windows 10/11 full live install/reset and scheduled
sleep/resume coverage remain open. Automated regression tests simulate desktop
calls and exercise disposable registry/folder data. Check the linked Actions run
for results for this exact commit.

Only Starter is bundled. Sunbeam Kitty's image-reference source is unverified and
excluded from the ZIP. GitHub's automatic source archives still reflect the full
repository and are not the packaged build.

Reset is not a factory reset or a full PC backup. Keep original wallpapers,
installed files and the `.state` backup until reset completes. See the included
`START-HERE.md`, `docs/USAGE.md`, `docs/SAFETY.md` and `THIRD_PARTY_NOTICES.md`.
