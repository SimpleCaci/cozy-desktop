# Community conduct

Cozy Desktop is a personal project with room for people who are learning Windows,
PowerShell, C#, or open-source work for the first time.

Be patient with questions. Explain a problem without insulting the person who
reported it. Critique code and design choices, avoid personal attacks, and respect
people's names and pronouns. Harassment, discrimination, threats, doxxing and spam
are not welcome.

Keep screenshots and logs free of other people's private information. Ask before
reposting someone's artwork, and include its source and permission when proposing
a theme.

The maintainer may edit or remove inappropriate content, close a discussion, or
restrict participation. Use GitHub's report-abuse controls for harassment. For a
repository security vulnerability, use the private channel in [SECURITY.md](SECURITY.md).

This policy applies to project Issues, pull requests, Discussions, and other spaces
maintained for this repository.
